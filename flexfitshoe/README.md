# AI Generated Shoes Website

A simple single-page shoes website created during an IBM Masterclass.

## Project Overview

This project was developed as part of a learning session focused on AI-assisted web development and prompt engineering. The website showcases a modern shoes landing page design.

## Features

- Responsive design
- Modern landing page layout
- Product showcase section
- Clean user interface

## Technologies Used

- HTML
- CSS
- ChatGpt
- AI Prompt Engineering

## Learning Outcome

Learned how AI tools and prompt engineering can assist in building web interfaces and accelerating web development workflows.
